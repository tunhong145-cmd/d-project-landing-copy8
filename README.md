# D 項目・複製倉庫八

自訂域名待定。包含 C（根目錄）、E（/e/）、F（/f/）、G（/g/）、I（/i/）、J（/j/）、K（/k/）七個版本。

## 当前 FB 配置隔离

本倉庫使用固定配置編號 `copy8`，後台入口為「複製倉庫八 · 域名待定」。七個版本獨立讀取 `repository_fb_pixels`，每版最多 5 個。初始像素為空；空配置或讀取失敗不使用其他倉庫像素。LINE、訂單、編號邏輯沿用現有流程。

独立的两页式贷款需求登记站点。

- `index.html`：贷款金额选择页
- `apply.html`：资料申请表与成功状态
- `styles.css`：响应式视觉样式
- `app.js`：金额传递、表单验证和 D 项目 Supabase 回传

客户填写资料：姓名、电话、出生年月日、LINE 帐号、贷款金额、是否为警示户。

站点前台不显示公司名称。客户资料继续进入现有 D 项目后台。
